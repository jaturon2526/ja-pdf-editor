ข้อกำหนดและเงื่อนไขการใช้บริการ

มีผลตั้งแต่ 21 ตุลาคม 2569 · ใช้กับเว็บไซต์ ja-pdf.com และบริการ JA PDF Editor

1. บทนำและการยอมรับข้อตกลง

ยินดีต้อนรับสู่ JA PDF Editor ("บริการ") โดยการเข้าถึงและใช้งานบริการนี้ ท่านตกลงที่จะผูกพันตามข้อกำหนดและเงื่อนไข ("ข้อตกลง") เหล่านี้ และนโยบายความเป็นส่วนตัว หากท่านไม่เห็นด้วยกับส่วนใดส่วนหนึ่ง โปรดงดเว้นการใช้งานบริการ

2. สิทธิในเอกสารของท่าน

เอกสารทั้งหมดที่ท่านอัปโหลดยังคงเป็นทรัพย์สินของท่าน เราไม่เรียกร้องสิทธิความเป็นเจ้าของในเนื้อหาใดๆ ของท่าน ท่านให้สิทธิแก่ระบบเพียงเพื่อประมวลผล จัดเก็บ และดัดแปลงไฟล์ตามคำสั่งของท่าน (เช่น แก้ไขข้อความ แปลงไฟล์ ส่งให้ผู้อื่นลงนาม) ท่านรับรองว่ามีสิทธิโดยชอบในการอัปโหลดและประมวลผลเอกสารนั้น

3. บัญชีผู้ใช้

  • ท่านต้องให้ข้อมูลที่ถูกต้อง และรับผิดชอบการรักษารหัสผ่าน passkey และอุปกรณ์ที่ใช้เข้าสู่ระบบ
  • ท่านลบบัญชีได้ทุกเมื่อที่หน้า "โปรไฟล์" ซึ่งจะลบไฟล์และข้อมูลของท่านตามที่ระบุในนโยบายความเป็นส่วนตัว

4. การลงนามเอกสารทางอิเล็กทรอนิกส์

  • ผู้ส่งเอกสารรับผิดชอบความถูกต้องของเนื้อหาเอกสาร และการระบุชื่อ/อีเมลของผู้ลงนาม
  • ผู้ลงนามรับผิดชอบการลงนามด้วยตนเอง ระบบเก็บประวัติการลงนาม (เวลา หมายเลข IP ข้อมูลเบราว์เซอร์) เป็นหลักฐานให้เจ้าของเอกสาร
  • ผลทางกฎหมายของลายมือชื่ออิเล็กทรอนิกส์เป็นไปตามพระราชบัญญัติว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544 และกฎหมายที่เกี่ยวข้อง ท่านควรพิจารณาว่าเอกสารประเภทใดต้องใช้วิธีลงนามหรือการรับรองแบบใดเพิ่มเติม

5. การใช้บริการ AI และบุคคลที่สาม

คุณสมบัติบางอย่าง (เช่น OCR การแก้ไขข้อความที่ผิดเพี้ยน การแปลงไฟล์) ใช้ปัญญาประดิษฐ์ของบุคคลที่สาม (Google Gemini API)

  • ท่านตกลงที่จะไม่ใช้ฟีเจอร์ AI กับเนื้อหาที่ผิดกฎหมาย อนาจาร หรือละเมิดสิทธิของผู้อื่น และปฏิบัติตามนโยบายการใช้งานของผู้ให้บริการ API
  • หากท่านให้ API key ส่วนตัว ระบบจะเข้ารหัสจัดเก็บ และใช้ส่งคำขอในนามของท่านเท่านั้น ค่าใช้จ่ายจาก API key ส่วนตัวเป็นความรับผิดชอบของท่าน
  • ผลลัพธ์จาก AI อาจผิดพลาด ท่านควรตรวจทานก่อนนำไปใช้

6. การใช้งานที่ต้องห้าม

  • อัปโหลดหรือเผยแพร่ซอฟต์แวร์ที่เป็นอันตราย (malware, virus) ภายในไฟล์
  • ใช้ระบบในทางที่ก่อภาระหนักผิดปกติกับเซิร์ฟเวอร์ หรือส่งคำขอสแปม
  • พยายามหลบเลี่ยงโควต้าพื้นที่เก็บข้อมูลหรือโควต้าการใช้ AI
  • ใช้บริการส่งเอกสารลงนามเพื่อหลอกลวง ฟิชชิง หรือแอบอ้างเป็นผู้อื่น
  • เจาะระบบ หรือพยายามเข้าถึงบัญชี ไฟล์ หรือข้อมูลของผู้ใช้อื่น

ซอฟต์แวร์ของบริการนี้เป็นโอเพนซอร์สภายใต้ GNU AGPL-3.0 ท่านดาวน์โหลด ศึกษา แก้ไข และนำไปติดตั้งเองได้ที่ github.com/jaturon2526/ja-pdf-editor ตามเงื่อนไขของสัญญาอนุญาตนั้น (ข้อตกลงนี้ใช้กับการใช้ บริการ ja-pdf.com ไม่จำกัดสิทธิ์ตาม AGPL-3.0)

7. ข้อจำกัดความรับผิดชอบ

บริการนี้ให้บริการตามสภาพ ("AS IS") โดยไม่มีการรับประกันใดๆ ไม่ว่าโดยชัดแจ้งหรือโดยปริยาย เท่าที่กฎหมายอนุญาต ผู้พัฒนาไม่รับผิดชอบต่อ:

  • การสูญหาย เสียหาย หรือการรั่วไหลของข้อมูลและเอกสาร
  • ความผิดพลาดในการประมวลผลไฟล์ (เช่น ไฟล์เสียหาย หรือข้อความผิดเพี้ยนจาก OCR)
  • ความเสียหายทางอ้อม ความเสียหายเกี่ยวเนื่อง หรือการสูญเสียผลกำไรทางธุรกิจ

ขอแนะนำให้เก็บสำเนาต้นฉบับของไฟล์สำคัญทุกครั้งก่อนใช้เครื่องมือที่ดัดแปลงไฟล์ เช่น การเซ็นเซอร์ข้อความ หรือ Flatten PDF

8. การเปลี่ยนแปลงบริการ ข้อตกลง และการระงับบัญชี

เราอาจปรับปรุง เปลี่ยนแปลง หรือยุติบางฟีเจอร์ และอาจแก้ไขข้อตกลงนี้ โดยจะแจ้งการเปลี่ยนแปลงที่สำคัญในระบบหรือทางอีเมล เราขอสงวนสิทธิระงับหรือยกเลิกบัญชีที่ละเมิดข้อตกลงนี้

9. กฎหมายที่ใช้บังคับ

ข้อตกลงนี้อยู่ภายใต้กฎหมายแห่งราชอาณาจักรไทย
