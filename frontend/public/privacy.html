มีผลตั้งแต่ 21 ตุลาคม 2569 (ปรับปรุง 8 พฤศจิกายน 2569: การสนับสนุนและการตรวจสลิป) · ใช้กับเว็บไซต์ ja-pdf.com และบริการ JA PDF Editor

JA PDF Editor ("บริการ", "เรา") เป็นเว็บแอปสำหรับแก้ไขไฟล์ PDF แปลงไฟล์ และส่งเอกสารให้ผู้อื่นลงนามทางอิเล็กทรอนิกส์ นโยบายนี้อธิบายว่าเราเก็บข้อมูลส่วนบุคคลอะไร ใช้เพื่ออะไร ส่งต่อให้ใคร เก็บนานเท่าไร และคุณมีสิทธิอะไรบ้าง ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

1. ข้อมูลที่เราเก็บ

ประเภทรายละเอียดได้มาจาก
ข้อมูลบัญชีอีเมล ชื่อที่แสดง รูปโปรไฟล์ (ถ้ามี) รหัสผ่านในรูปแบบที่เข้ารหัสทางเดียว (hash) วันที่สมัคร แพ็กเกจการใช้งานคุณกรอกตอนสมัคร
ข้อมูลจาก Googleเมื่อคุณเลือก "เข้าสู่ระบบด้วย Google" เราได้รับเฉพาะ อีเมล ชื่อ และลิงก์รูปโปรไฟล์ ของบัญชี Google — เราไม่เข้าถึง Gmail, Drive, รายชื่อติดต่อ หรือข้อมูลอื่นใดในบัญชี Google ของคุณGoogle Sign-In
Passkeyกุญแจสาธารณะ (public key) และชื่ออุปกรณ์ที่คุณตั้ง — ข้อมูลลายนิ้วมือหรือใบหน้าไม่เคยออกจากอุปกรณ์ของคุณเมื่อคุณเพิ่ม passkey
ไฟล์เอกสารไฟล์ PDF และไฟล์อื่นที่คุณอัปโหลด ไฟล์ที่แปลงแล้ว ลายเซ็นและฟอนต์ที่คุณบันทึกไว้คุณอัปโหลด
การลงนามเอกสารชื่อและอีเมลของผู้ลงนามที่ผู้ส่งระบุ ลายเซ็น เวลาที่ดำเนินการ หมายเลข IP และข้อมูลเบราว์เซอร์ (user agent) ขณะเปิด/ลงนาม/ปฏิเสธเอกสาร เพื่อใช้เป็นหลักฐานการลงนามผู้ส่งเอกสารและผู้ลงนาม
LINEเมื่อคุณเลือก "เข้าสู่ระบบด้วย LINE": รหัสผู้ใช้ LINE (user ID) ชื่อที่แสดง ลิงก์รูปโปรไฟล์ และอีเมลที่ลงทะเบียนกับ LINE (เฉพาะเมื่อคุณอนุญาตในหน้าของ LINE) รวมถึงสถานะว่าเป็นเพื่อนกับ LINE Official Account ของเราหรือไม่ — อีเมลใช้สร้างบัญชี เชื่อมกับบัญชีเดิมที่ใช้อีเมลเดียวกัน และส่งการแจ้งเตือน · เมื่อคุณผูกรับแจ้งเตือน: รหัสผู้ใช้ LINE และชื่อที่แสดงLINE Login / LINE Official Account ของเรา
API key ของ AIAPI key ส่วนตัวที่คุณใส่เอง (Gemini / Claude / OpenAI หรือ API ที่เลือก ถ้ามี) จัดเก็บแบบเข้ารหัส พร้อมชื่อผู้ให้บริการ รุ่น และ URL ของ API ที่ตั้งไว้คุณกรอก
การสนับสนุน (บริจาค)เมื่อคุณแจ้งโอนผ่านหน้า "สนับสนุนผู้พัฒนา": ยอดเงิน วันเวลาที่โอน ชื่อที่ต้องการแสดง ข้อความ และรูปสลิป (ถ้าแนบ) — สลิปถูกลบทันทีที่ผู้ดูแลตรวจเสร็จ (ระหว่างรอตรวจเห็นได้เฉพาะผู้ดูแลระบบ) · ระบบอ่านเลขอ้างอิงรายการจาก QR ในสลิปเก็บไว้เพื่อกันสลิปซ้ำ · ถ้าผู้ดูแลเปิดการตรวจสลิปอัตโนมัติ ระบบส่งเฉพาะข้อความใน QR ของสลิป (ไม่ส่งรูป) ไปยังผู้ให้บริการตรวจสลิป (EasySlip) เพื่อขอยอดเงิน วันเวลา และชื่อผู้โอน/ผู้รับจากธนาคาร แล้วเก็บผลไว้ประกอบการอนุมัติ · หน้ารายชื่อผู้สนับสนุนแสดงเฉพาะชื่อที่คุณเลือก (หรือ "ไม่ประสงค์ออกนาม") และข้อความ ไม่แสดงยอดเงินและอีเมล · การชำระเงินทำผ่านแอปธนาคารของคุณโดยตรง เราไม่ได้รับข้อมูลบัญชีธนาคารคุณกรอก
ข้อมูลการใช้งานจำนวนครั้งที่ใช้ฟีเจอร์ AI ต่อวัน การแจ้งเตือนในระบบ และบันทึกของเซิร์ฟเวอร์ (log) ที่จำเป็นต่อความปลอดภัยและแก้ไขปัญหาระบบบันทึกอัตโนมัติ

เราไม่ใช้คุกกี้โฆษณาหรือเครื่องมือติดตามของบุคคลที่สาม เบราว์เซอร์ของคุณเก็บเฉพาะโทเค็นเข้าสู่ระบบ (ใน local storage) เพื่อให้คุณอยู่ในระบบ

2. วัตถุประสงค์และฐานทางกฎหมาย

  • ให้บริการตามที่คุณขอ (ฐานสัญญา) — สร้างและยืนยันบัญชี เข้าสู่ระบบ เก็บและประมวลผลไฟล์ ส่งเอกสารให้ผู้ลงนาม ส่งอีเมล/LINE แจ้งเตือนเกี่ยวกับเอกสาร
  • รักษาความปลอดภัยและหลักฐาน (ประโยชน์โดยชอบด้วยกฎหมาย) — ป้องกันการเข้าถึงโดยมิชอบ จำกัดการใช้งานเกินโควต้า เก็บหลักฐานการลงนามให้เจ้าของเอกสาร
  • ปฏิบัติตามกฎหมาย — เมื่อมีคำสั่งจากหน่วยงานที่มีอำนาจตามกฎหมาย

เราไม่ขาย ไม่ให้เช่า และไม่ใช้ข้อมูลหรือเนื้อหาไฟล์ของคุณเพื่อโฆษณา

3. การใช้ข้อมูลที่ได้รับจาก Google

การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google APIs ของ JA PDF Editor เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use — เราใช้อีเมล ชื่อ และรูปโปรไฟล์จาก Google เพื่อสร้างบัญชีและให้คุณเข้าสู่ระบบเท่านั้น ไม่ส่งต่อให้ผู้อื่น และไม่ใช้เพื่อโฆษณาหรือฝึกโมเดล AI

4. ผู้ให้บริการภายนอกที่ประมวลผลข้อมูลแทนเรา

ผู้ให้บริการใช้ทำอะไรข้อมูลที่เกี่ยวข้อง
Oracle Cloud Infrastructureเซิร์ฟเวอร์ ฐานข้อมูล และที่เก็บข้อมูลสำรอง (สำรองนอกเซิร์ฟเวอร์ถูกเข้ารหัสก่อนส่ง)ข้อมูลทั้งหมดของบริการ
CloudflareDNS และส่งต่อการรับส่งข้อมูลของเว็บไซต์หมายเลข IP ข้อมูลการเชื่อมต่อ
Google (Sign-In)เข้าสู่ระบบด้วยบัญชี Google (เฉพาะเมื่อคุณเลือก)อีเมล ชื่อ รูปโปรไฟล์
ผู้ให้บริการ AI ที่ตั้งไว้ (Google Gemini, Anthropic Claude, OpenAI หรือ API ที่ผู้ดูแลระบบ/คุณเลือก)ฟีเจอร์ AI เช่น OCR และแก้ข้อความ — ส่งเฉพาะเนื้อหา/หน้าเอกสารที่คุณสั่งประมวลผลด้วย AIเนื้อหาเอกสารส่วนที่เลือก
Brevoส่งอีเมลยืนยันบัญชี รีเซ็ตรหัสผ่าน และแจ้งเตือนการลงนามอีเมล ชื่อ หัวข้อเอกสาร
LINE (LY Corporation)เข้าสู่ระบบด้วย LINE และส่งแจ้งเตือนทาง LINE (เฉพาะเมื่อคุณเลือกใช้)LINE user ID ชื่อ อีเมล หัวข้อเอกสาร
EasySlip (เฉพาะเมื่อผู้ดูแลเปิดตรวจสลิปอัตโนมัติ)ตรวจรายการโอนเงินกับธนาคาร เพื่อยืนยันการสนับสนุนข้อความใน QR ของสลิป (เลขอ้างอิงรายการ) · ผลที่ได้กลับ: ยอด วันเวลา ชื่อผู้โอน/ผู้รับ

ผู้ให้บริการบางรายอาจประมวลผลข้อมูลนอกประเทศไทย (เช่น มาเลเซีย สิงคโปร์ สหรัฐอเมริกา ญี่ปุ่น) โดยอยู่ภายใต้มาตรการคุ้มครองข้อมูลตามข้อตกลงการให้บริการของแต่ละราย หากคุณไม่ต้องการให้เนื้อหาเอกสารถูกส่งไปยัง AI ให้หลีกเลี่ยงการใช้ฟีเจอร์ที่ระบุว่าใช้ AI

5. การเปิดเผยข้อมูลให้ผู้ใช้อื่น

เมื่อคุณส่งเอกสารให้ผู้อื่นลงนาม ผู้ลงนามจะเห็นชื่อและอีเมลของคุณ รวมถึงเอกสารที่ส่ง เมื่อคุณลงนามเอกสารของผู้อื่น เจ้าของเอกสารจะได้รับลายเซ็น ชื่อ อีเมล และประวัติการลงนามของคุณ (รวมเวลาและหมายเลข IP) ซึ่งเป็นหลักฐานของเจ้าของเอกสาร

6. ระยะเวลาเก็บข้อมูล

  • บัญชีและไฟล์ — เก็บจนกว่าคุณจะลบไฟล์หรือลบบัญชี
  • เมื่อลบบัญชี — ไฟล์ ข้อมูลบัญชี passkey การเชื่อมต่อ LINE และการตั้งค่าทั้งหมดถูกลบทันที ยกเว้นประวัติการลงนามในเอกสารของผู้อื่น ซึ่งเก็บชื่อและอีเมลไว้เป็นหลักฐานของเจ้าของเอกสาร โดยไม่เชื่อมกับบัญชีแล้ว
  • การสนับสนุน — สลิปลบเมื่อตรวจเสร็จ · ยอด วันที่ และเลขอ้างอิงรายการเก็บไว้เป็นบันทึกรายรับ · เมื่อลบบัญชี ชื่อ ข้อความ และผลตรวจสลิป (ชื่อผู้โอน) ถูกลบทันที
  • ข้อมูลสำรอง — ข้อมูลที่ลบแล้วอาจยังอยู่ในชุดสำรองข้อมูลจนกว่าชุดนั้นจะหมดอายุ: ชุดสำรองบนเซิร์ฟเวอร์ 14 วัน และชุดสำรองนอกเซิร์ฟเวอร์ (เข้ารหัส) 30 วัน ชุดสำรองใช้เพื่อกู้ระบบเมื่อเกิดเหตุขัดข้องเท่านั้น
  • บันทึกของเซิร์ฟเวอร์ — เก็บตามระยะเวลาที่จำเป็นต่อความปลอดภัยและแก้ไขปัญหา แล้วลบหรือหมุนเวียนทับ

7. ความปลอดภัย

เราเชื่อมต่อผ่าน HTTPS เก็บรหัสผ่านแบบ hash เข้ารหัส API key ที่คุณให้ไว้ เข้ารหัสข้อมูลสำรองก่อนส่งออกนอกเซิร์ฟเวอร์ และจำกัดการเข้าถึงเซิร์ฟเวอร์เฉพาะผู้ดูแลระบบ อย่างไรก็ตาม ไม่มีระบบใดปลอดภัยสมบูรณ์ หากเกิดเหตุละเมิดข้อมูลที่มีความเสี่ยงต่อสิทธิของคุณ เราจะแจ้งสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคลและแจ้งคุณตามที่กฎหมายกำหนด

8. สิทธิของคุณ

ตาม PDPA คุณมีสิทธิ:

  • ขอเข้าถึงและขอรับสำเนาข้อมูลส่วนบุคคลของคุณ
  • ขอแก้ไขข้อมูลให้ถูกต้อง — แก้ชื่อที่แสดงได้เองที่หน้า "โปรไฟล์"
  • ขอลบข้อมูล — ลบบัญชีได้เองที่หน้า "โปรไฟล์" → "ลบบัญชี"
  • ขอให้โอนย้ายข้อมูล — ดาวน์โหลดไฟล์ของคุณได้จากหน้า "เอกสารของฉัน"
  • คัดค้านหรือขอให้ระงับการประมวลผล และถอนความยินยอม (เช่น ยกเลิกการเข้าสู่ระบบด้วย LINE หรือการแจ้งเตือนทาง LINE ได้ที่หน้า "ความปลอดภัย")
  • ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (pdpc.or.th)

เราจะตอบคำขอภายใน 30 วันนับจากวันที่ได้รับคำขอ และอาจขอยืนยันตัวตนก่อนดำเนินการ

9. ผู้เยาว์

บริการนี้ไม่ได้มุ่งให้บริการแก่ผู้ที่อายุต่ำกว่า 20 ปีที่ยังไม่ได้รับความยินยอมจากผู้ใช้อำนาจปกครอง

10. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงที่สำคัญ เราจะแจ้งในระบบหรือทางอีเมลก่อนมีผล และปรับวันที่ "มีผลตั้งแต่" ด้านบน
