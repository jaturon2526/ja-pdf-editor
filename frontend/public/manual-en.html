JA PDF Editor User Manual

Welcome to JA PDF Editor, your all-in-one PDF workspace — from editing text and images, managing pages, and converting to Word, to sending documents for sequential multi-party signing. Files you upload are stored privately in your account's "My Documents" space; no one else can see them, and you can delete them at any time.

# 1. Opening, Saving & Printing Documents

You can open PDF files or Office documents (Word, Excel, PowerPoint) to convert to PDF, save, download, or print immediately.

  1. Open a File: Click File > Open..., press Ctrl + O (⌘ + O), or drag and drop a file onto the center of the workspace.
  2. Create PDF from Office Files: Go to File > Create from Office... and select a Word, Excel, or PowerPoint file (.docx, .doc, .xlsx, .xls, .pptx, .ppt, .rtf, .odt, .ods, .odp) — the app converts it to PDF and saves it as a .pdf file in My Documents right away (same filename with a .pdf extension), then opens it for editing · The original Office file is not stored · You can also upload Office files directly from My Documents the same way (Section 21).
  3. Save (Overwrite Original): Click the icon on the Toolbar or go to File > Save (Overwrite) (shortcut Ctrl + S / ⌘ + S) to save your edits to the file in My Documents — changes are saved to My Documents only when you click Save (downloading or printing does not save) · If you have unsaved edits when returning to My Documents, opening another file, closing the file, or closing the tab, the app will prompt you first.
  4. Download to Device: Once finished editing, click the icon or File > Download to save the PDF (with your latest edits) to your computer — the file in My Documents remains unchanged · If a password is set, the downloaded file retains that password.
  5. Print Document: Click the printer icon on the Toolbar or go to File > Print... (shortcut Ctrl + P / ⌘ + P). Prints your latest edits (without overwriting the file in My Documents · password-protected PDFs can also be printed without re-entering the password) and opens the OS print dialog at full vector sharpness — If the document has landscape pages, it will ask your print orientation preference; choosing Print as shown on screen is recommended to avoid upside-down pages · On mobile/tablet & Safari, the document opens in a new tab so you can tap Share › Print (or the browser print menu) — if your browser blocks pop-ups, a print-ready file is downloaded instead.
  6. Save as New Copy: To keep a separate version, use File > Save As... to create a new file without overwriting the original (duplicate filenames get (2), (3) appended · characters / \ : * ? " < > | are not allowed in filenames)
    • Select PDF Version (1.4, 1.5, 1.6, 1.7, 2.0) or Keep Unchanged — the output strictly conforms to that standard rather than merely changing the header number: every object is checked, unsupported features are converted, and the output is re-verified before saving.
    • Choosing a lower PDF version: layers are flattened as displayed and JPEG 2000 images are converted (losslessly) — text, links, bookmarks, highlights, text boxes, and form fields remain intact, and the status bar reports what was converted.
    • Password-protected files are encrypted according to version — 1.4/1.5 uses RC4 128-bit (less secure), 1.6/1.7 uses AES-128, and 2.0 uses AES-256.
    • Documents with digital signatures cannot change PDF version (as it would invalidate the signature) — select "Keep Unchanged".
    • PDF/A (Long-Term Archiving — ISO 19005): Choose PDF/A-1b (broadest compatibility), PDF/A-2b (recommended), or PDF/A-3b — looks identical across all viewers: embeds all fonts, adds an sRGB color profile, and embeds compliance metadata · Highlights, text boxes, and form fields are flattened into page content (no longer editable), while text stays searchable and links/bookmarks remain functional · PDF/A-1 does not support transparency, so transparent images are composited onto white · PDF/A forbids passwords; remove any password first.
  7. Document Properties & Certificates: Check metadata (title, author, embedded fonts, page dimensions) and Digital Signature Trust & Certificate Expiry status via File > Document Properties...

# 2. Editing Text & Images

Edit existing text directly in a PDF, add new text, edit/move/delete existing images, insert new images, or redact sensitive text and images.

  • Add Text: Click the (Text lines with plus) icon on the toolbar, choose your desired font, size, and color, then click anywhere on the page to type (full Thai script support) — can be placed over existing text without erasing it (ideal for filling blanks on forms).
  • Add Image: Click the (Image with plus) icon or go to Insert > Insert Image — the file picker opens immediately; once chosen, the image appears in the center of the page. Drag the image to move it, drag the corner/edge handles to resize, then click Confirm and Save Changes.
  • Edit Existing Text (Native Text Edit): Go to Tools > Edit Text to detect all existing text blocks on the PDF page. Click any block to edit it directly — change font, size, color, alignment, underline, or delete the original text. When done, click Confirm and then Save Changes to write to the file · Inside tables, text boxes are isolated per cell (never merged across columns); wrapped lines in the same cell form one box, and if new text is slightly longer (e.g. 92 → 100), the box widens within the cell rather than wrapping mid-number.

# 6. Watermarks and Passwords

8.1 Save Certificates to Your Account

🔑 Unlock with a Passkey Instead of Typing Password

Bind a passkey (Face ID / Touch ID / fingerprint / Windows Hello) to a saved certificate so you can verify biometrically instead of typing the certificate password when signing or deleting — requires an existing passkey on your account (in the Passkey section at the top of the Security page).

# 16. Search & Redact

Search for sensitive words or phrases across a document and permanently redact (black out) every occurrence automatically.

  1. Open the PDF file you want to redact.
  2. Go to Tools → Search & Redact...
  3. Type the word or phrase you want to redact in the search box.
  4. (Optional) Check Use Regular Expression (Regex) for advanced patterns such as a 13-digit National ID number.
  5. Click Redact All Matches; the system blacks out every match across the entire document.
  • Type normal Thai words: The search engine matches words even when the PDF stores malformed Thai characters (e.g., Word exports storing "สระอำ" as "จ าเป็น" or official letters extracting as "ส ำนักงำน"), and even when words wrap across lines or contain extra spaces ("บริษัท ตัวอย่าง" = "บริษัทตัวอย่าง").
  • Removes data everywhere in the file: Beyond page text, the system also replaces matching text with ███ inside form field values, sticky notes/comments, bookmark titles, and PDF metadata (Title, Author) so no hidden data can be viewed or copied.
  • Regex: Patterns with nested quantifiers like (a+)+ are rejected to prevent freezing; use simple patterns like 0[689]\d-?\d{3}-?\d{4} (mobile numbers).
  • Text inside images cannot be searched directly — such as signature images containing signer names/titles, stamps, or scanned pages. When no text match is found, the system tells you which pages contain images and offers a Recognize Text in Images (OCR) & Search Again button — it runs OCR and places an invisible text layer over the exact spot (visual appearance stays unchanged), letting you redact both the text layer and the underlying image pixels. · You can also pre-run OCR on the whole document via Tools → Recognize Text (OCR) (which also enables copying and PDPA scanning inside images, and can be undone). · OCR may misread occasional characters; review results before saving, or use the Redact Box tool to cover remaining areas manually.

Warning: Redaction permanently destroys the underlying data and cannot be undone once saved. We recommend keeping a backup copy of the original file.

# 22. Send Document for Signing (Sequential / Parallel)

Send a PDF document to multiple signers in sequence—for example, Approver → Executive. The system notifies each person when it is their turn, locks the document content against edits along the way, and automatically places the completed signed file back in the sender's My Documents once everyone has signed.

Sending Steps

  1. On My Documents, click the Send for Signing card (in the Document Signing group) and choose a file — or click the ☰ button on a file and choose Send for Signing.
  2. Enter the Document Title (pre-filled from the filename) and an optional Message to Signers. This message appears on the request page and in notification emails.
  3. Signing Deadline (optional): Pick a date and time. The system reminds signers when fewer than 24 hours remain and notifies you if it becomes overdue.
  4. In the Signers box, type an email address and press Enter:
    • Shows ✓ Username = Already has an account in the system.
    • Shows ✉ Not registered yet = The system will email an invitation to register with that email address (see Section 25).
  5. Choose each person's Signature Type: Electronic Signature, Digital Signature (.p12/.pfx certificate), or Signer's Choice (lets the signer decide).
  6. (Optional) Check Require Passkey verification before signing for that signer — they must verify with their account's passkey (face/fingerprint) before signing, proving the account owner signed personally (not someone else who knows their password), and the verification is recorded on the Certificate of Completion.
  7. Click Place Signature Box, then move your mouse over the document — a box follows your cursor. Click where you want to place it (you can switch pages before clicking, or press Esc to cancel). Once placed, drag it to move or drag its corners to resize.
  8. Click + Add Signer to add the next person. Use ↑ ↓ to reorder or ✕ to remove.
  9. Check the gray hint checklist below the button (if any, such as an unplaced signature box), then click Send for Signing (N signers).

Sequential or Parallel Signing

  • Sequential (default): Each person is in a separate step; the next signer is notified after the previous signer finishes.
  • Parallel: Check Sign together with previous signer on that signer. Both are placed in the same step (sharing the same circle number), notified at the same time, and can sign in any order. The next step begins once everyone in that step has signed.
⚠️ Good to know: Once sent, the document content, signer list, and deadline cannot be edited. To make changes, Cancel the request and send a new one. Files with rotated (landscape) pages work normally for signing; signature boxes stay right where they appear on screen.

# 23. Signing a Document Request (For Signers)

When it is your turn, you will receive an alert at the top-right Bell icon and an "It's your turn to sign" email with a button to open the document.

  1. Click the notification, or go to the Signing menu › Waiting for Me tab and click the document title (items awaiting your turn carry a Your turn badge).
  2. Read through all pages of the document (‹ › buttons at the top) — the blue box labeled (You) shows your signature placement.
  3. In the Your Turn to Sign panel on the right, choose:
    • Electronic Signature: Create your signature by typing your name, uploading an image, or drawing with mouse/touch, pick an ink color, and click OK (uploaded signature images must be PNG/JPG containing an actual signature — mobile photos are automatically rotated upright).
    • Digital Signature (Certificate): Pick a saved certificate or your .p12/.pfx certificate file, enter its password (optionally add a signature image), and click OK.

    🔑 Passkey Verification: If your account has a passkey (Section 26.1), clicking the sign button prompts your device for face/fingerprint verification before opening the signing modal — the system records "Verified with Passkey (Device Name)" in the signer list, audit history, and Certificate of Completion.

    • Optional: You can uncheck Verify with Passkey before signing.
    • Required by sender: Shows Sender requires Passkey verification — if you do not have a passkey yet, click the Add passkey on Security page link, then return to the request.
    • You cannot substitute someone else's passkey; the system verifies that the passkey belongs to the currently signed-in account.
  4. Once Signed successfully appears, the system automatically notifies the next signer.
  5. If you disagree with the document, click Decline and enter a reason — the request stops immediately, and the sender is notified with your reason.
🛡️ How secure are electronic signatures in this system? They are not merely images pasted onto a page—they are real PDF signatures (PAdES) signed by the system with your verified account name and email. The signature stamp has a transparent background so it never obscures underlying text, and if the document is altered after signing, signature verification immediately flags it as invalid.

# 24. Track Status, Send Reminders, and Certificate of Completion

"Signing" Page

On My Documents, the Document Signing group shows Waiting for Me (with a red badge count when documents await you) and Sent by Me, or click View All →. The list has 3 tabs: Waiting for Me, Sent by Me, and All. Each row shows the status, how many have signed, who is currently awaited, and the deadline (marked Overdue once past due).

What the Sender Can Do on the Request Page

  • Send Reminder: Sends an in-app alert and email to everyone currently awaited (can be repeated every 60 minutes) — for invited signers who haven't registered yet, the invitation email is re-sent.
  • Cancel This Request: Immediately stops signing and notifies pending signers (available only for unfinished requests).
  • Download Document (Latest Version): Downloads the PDF including all signatures completed so far.
  • Verify Signatures in Document: Checks every signature to confirm the document has not been modified after signing, displaying certificate names and TSA timestamps (if enabled by the administrator).
  • Audit History (Evidence): Logs every event — Sent, Viewed, Signed, Reminded, Declined — with timestamps and IP addresses.

Certificate of Completion

Click Download Certificate of Completion to get a PDF summary of all evidence: signers, signing methods, timestamps, IP addresses, full event history, and SHA-256 hashes of both the original and latest versions. The system digitally signs this certificate to prevent tampering. Both the sender and every signer can download it.

🔍 Verify that the file you hold is the exact signed copy: Compute the file's SHA-256 hash (macOS/Linux: shasum -a 256 filename.pdf · Windows: certutil -hashfile filename.pdf SHA256) and compare it with "Latest SHA-256" in the certificate—every character must match.

When Everyone Has Signed

  • Everyone receives an "All signers have signed" notification via both the bell icon and email.
  • A file named "Document Title (Signed).pdf" is saved in the sender's My Documents.
  • Do not edit the contents of a signed file (such as opening it in the Editor and saving), as this invalidates the signatures. Download it as-is for use or distribution.
  • When opened in Adobe Acrobat, signatures report "Document has not been modified." Whether a green checkmark appears depends on the certificate used: digital signatures follow the signer's certificate trust, while electronic signatures follow the system certificate configured by the administrator.

Email Notifications

  • The system sends emails when: it is your turn to sign · a reminder is sent · the deadline is near · the deadline passes · someone declines · signing completes · a request is cancelled.
  • Emails are sent from the system address, with the sender name formatted as "Requester Name via JA PDF Editor," and clicking Reply addresses the requester directly.
  • To opt out of emails: uncheck Receive signing notification emails on the Signing page (bell notifications remain active).
  • Not seeing emails? Check your Junk/Spam folder.

# 25. Invite Someone Without an Account to Sign

  2. In the Passkey section, click + Add Passkey, give it a recognizable name (such as "Work MacBook"), and click Create Passkey.
