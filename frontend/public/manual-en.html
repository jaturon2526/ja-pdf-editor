JA PDF Editor User Manual

Welcome to JA PDF Editor — an all-in-one PDF workspace for editing text, images, and tables, managing pages, converting PDFs to Word, scanning documents on mobile, redacting sensitive PDPA data, and sending documents for sequential electronic or cryptographic PAdES digital signing. Files uploaded to My Documents are private to your account and can be deleted at any time.

✨ What's New (v1.55.0)
  • Full Thai / English Multi-Language Support: Switch languages anytime in Profile → Language. Covers Login, Dashboard, all Quick Tool modals, Editor menus/toolbar, Profile/Security/AI Config/Support/Admin pages, notifications, emails, and this bilingual User Manual.
  • Mobile Document Scanner → Rebuild as Native PDF Objects: Choose between classic searchable-image OCR PDF or rebuilding scanned pages into editable vector text & tables with Thai spellcheck and optional AI proofreading.
  • Smooth Continuous Scroll: Seamless multi-page scrolling without flicker on both desktop and mobile.

1. Open, Save & Print Documents

  • Upload / Drag & Drop: Upload single or multiple PDFs, images (PNG/JPG), or Office files (Word, Excel, PowerPoint — auto-converted to PDF) from the Dashboard.
  • Save to Server (Ctrl+S): Saves your latest changes back to My Documents.
  • Download & Print (Ctrl+P): Export the edited PDF to your device or print directly.
  • Undo / Redo (Ctrl+Z / Ctrl+Y): Step backward or forward through every edit in the session.

2. Edit Text, Images & Tables

  • Insert / Edit Text: Click existing text to edit inline or place new Thai/English text with HarfBuzz-shaped vector rendering so Thai vowels and tone marks align cleanly.
  • Images: Insert PNG/JPG images, resize, rotate, replace, or delete existing images in the PDF.
  • Edit Tables: Detect and edit table cells directly, including multi-line Thai text and border preservation.
  • Inspect Fonts: Click any text on the page with the Font Inspector tool to see its font family, size, and color.

3. Highlights, Annotations & Fillable Forms

  • Highlight, Text Box, Rectangle & Sticky Notes: Mark up documents and review comments cleanly.
  • Create Blank PDF / Form Builder: From the Dashboard, click Create PDF Form to create an A4/Letter/A5/A3 or custom-size document and immediately open Form Builder mode to add text inputs, checkboxes, radio buttons, and dropdowns.
  • Fill Existing Forms: Open any AcroForm PDF to fill fields and save or flatten them.

4. Page Management, Extract & Crop

  • Sidebar Thumbnails: Drag to reorder pages, rotate left/right, duplicate, insert pages from another PDF, or delete pages.
  • Extract Pages: Export a specific page range (e.g. 1-3, 5) as a new PDF file.
  • Crop Pages: Trim margins interactively on the current page or apply to all pages.

5. Merge PDFs

Click Merge PDFs on the Dashboard to combine up to 30 PDF files from your device or My Documents. Drag or use the arrow buttons to arrange the order. The merged result is saved as a new PDF with automatic bookmarks for each source file.

6. Watermark, Passwords & Page Numbers

  • Add Watermark: Customize text, presets, color, angle, size, and opacity with live A4 preview.
  • Add Page Numbers: Choose 1, 2, 3 or 1/N, Thai or Arabic digits, prefix/suffix, start/end page, position, and duplex mirroring.
  • Encrypt PDF: Protect PDFs with AES-256 (recommended, supports Unicode/Thai passwords) or legacy AES-128. Original files remain untouched when run from Quick Tools.

6.2 Insert / Move / Delete Barcodes & QR Codes

Generate QR Codes (supporting UTF-8 Thai text) or 1D barcodes (Code 128, EAN-13, etc.) and place them anywhere on the page. Use the Move / Delete Barcode tool to reposition or remove existing barcodes cleanly.

7. Electronic Signatures

Draw your signature on screen, type with stylized fonts, or upload a signature image (with automatic white-background removal). You can also save up to 5 encrypted signature images locked with your Passkey in Security so the server never sees your raw signature image.

8. Cryptographic Digital Signatures (PAdES)

Sign PDFs using your .p12 / .pfx digital certificate with optional RFC 3161 trusted timestamping (TSA). Store up to 5 encrypted certificates under Security → Digital Signature Certificates — your password is never stored on the server, and you can optionally bind a Passkey for Face ID / Touch ID unlocking.

9. Auto-Gen Documents (Mail Merge)

Upload a Word template (.docx) containing {{ column_name }} placeholders and a data file (.xlsx, .csv, .txt, or .json) to generate batch Word or PDF documents in one click.

  • Supports dynamic tables, conditionals, QR codes, and barcodes inside templates.
  • Output as individual files in a .zip archive or combined into a single file.
  • Optional per-file PDF password encryption driven by a data column (e.g. employee ID or birth date).

10. Compress & Flatten PDF

  • Compress PDF: Choose Screen (smallest), eBook (balanced), or Printer (high quality) to shrink file size while keeping annotations and form fields intact.
  • Flatten PDF: Permanently merge form fields and annotations into page content so they can no longer be edited.

11. Copy Text with AI (Fusion OCR)

In the Editor, drag a selection box over any scanned region, image, or table to extract clean Thai/English text to your clipboard using OCR and optional AI proofreading.

12. Quick Tools, Mobile Scan & Compare PDFs

  • Convert PDF to Word: Auto-detects regular vs. scanned PDFs. Choose Freely Editable Text (with optional AI Thai proofreading) or Preserve Original Layout.
  • Mobile Document Scanner: Capture pages with auto edge detection and perspective correction, then save as either a searchable OCR image PDF or rebuild into editable native PDF objects.
  • Compare Documents: Highlight added, deleted, and modified text plus visual image differences side-by-side and download a comparison report.

13. AI API Key Configuration

Open Profile Menu → AI Settings (API Key) to check your daily system AI quota or connect your personal API key (Google Gemini, Anthropic Claude, OpenAI, Azure OpenAI, or self-hosted OpenAI-compatible endpoints like Ollama/vLLM). Personal keys are encrypted at rest and verified before saving.

14. Search & Redact / PDPA Personal Data Masking

  • Search & Redact: Permanently remove matching words or Regular Expressions across text, form fields, comments, bookmarks, and metadata.
  • PDPA Auto-Detection: Scans locally on the server (never sent to external AI) for National IDs, phone numbers, emails, bank accounts, credit cards, and names. Review checkboxes, apply permanent redaction, and download a CSV audit report.

15. Install Custom Fonts

Click Install Fonts on the Dashboard or in the Editor to add fonts directly from a Google Fonts URL/name or by uploading .ttf / .otf / .woff / .woff2 files (Regular, Bold, Italic, Bold Italic). Installed fonts become available immediately in the text editor.

16. Keyboard Shortcuts

Ctrl+O — Open file
Ctrl+S — Save to server
Ctrl+P — Print document
Ctrl+F — Find in document
Ctrl+Z / Ctrl+Y — Undo / Redo
Esc — Close active modal / cancel tool

17. Multi-Signer Document Workflow

Under Document Signing on the Dashboard, send any PDF to one or more signers in sequence (or invite recipients by email even if they don't have an account yet). Track live status, send reminders, receive notifications via the bell, email, or LINE, and download the completed signed PDF along with its Certificate of Completion.

18. Account, Language, Passkey & LINE

  • Profile & Language: Update your display name, upload or create an emoji avatar, switch your preferred language (Thai / English), or permanently delete your account.
  • Passkeys: Register Face ID, Touch ID, Windows Hello, or security keys under Security for phishing-resistant passwordless sign-in.
  • LINE Integration: Link your LINE account for one-click sign-in and instant LINE signing notifications.
