# บันทึกการแก้ไขและอัปเดตฟีเจอร์ Auto-Gen (Changelog)

เอกสารนี้ใช้สำหรับบันทึกประวัติการแก้ไขบั๊กและการเพิ่มฟีเจอร์ย่อย (Enhancements) นอกเหนือจากแผนหลัก เพื่อให้ทีมพัฒนาสามารถติดตามการเปลี่ยนแปลงและเทคนิคที่ใช้แก้ปัญหาได้

## อัปเดตล่าสุด: กันยายน 2026 (Phase 3 & 4)

### 🚀 ฟีเจอร์ที่เพิ่มเข้ามาใหม่ (Enhancements)
1. **การรองรับไฟล์หลากหลายรูปแบบ:**
   - เพิ่มการรองรับไฟล์ `.csv`, `.txt`, `.xlsx` สำหรับเป็นข้อมูล (Data source) นอกเหนือจาก `.json`
   - เพิ่มกลไกแปลงข้อมูลแบบ Flat file (1 แถว = 1 เอกสาร) ให้เป็นโครงสร้าง JSON อัตโนมัติ เพื่อป้อนเข้า `docxtpl`
2. **ระบบการตั้งชื่อไฟล์แบบอิสระ (Custom Filename Generation):**
   - ผู้ใช้สามารถตั้งชื่อไฟล์ได้ 2 รูปแบบ:
     - *Space-separated:* เช่น `invoice_no customer_name` จะนำค่ามาต่อกันด้วยช่องว่าง (เช่น `INV-001 คุณ สมชาย`)
     - *Jinja2 Syntax:* เช่น `{{invoice_no}}-{{customer_name}}` คืนค่าตาม format ที่พิมพ์เป๊ะๆ
   - นำคำว่า `doc_` และขีดล่าง `_` ที่เคยบังคับใส่ออก เพื่อให้ได้ชื่อไฟล์ตามที่ผู้ใช้ต้องการ 100%
   - **Fallback Logic:** หากไม่ได้ระบุชื่อไฟล์ ระบบจะดึง "ค่าของคอลัมน์แรกสุด" มาเป็นชื่อไฟล์ให้โดยอัตโนมัติ
3. **ป้องกันไฟล์ซ้ำ (Deduplication):**
   - เพิ่มระบบนับจำนวนชื่อไฟล์ที่ซ้ำกัน หากเกิดกรณีที่ 2 แถวมีข้อมูลชื่อเดียวกัน ระบบจะเติม `-2`, `-3` ต่อท้ายชื่อไฟล์ย่อยอัตโนมัติ เพื่อป้องกันไฟล์ทับกันสูญหายตอนแตกไฟล์ Zip
4. **Data Preview & Encoding:**
   - เพิ่ม Endpoint `/api/autogen/preview` สำหรับแสดงตัวอย่างข้อมูล 3 บรรทัดแรกก่อนกดสร้างเอกสาร
   - เพิ่มปุ่มขยายหน้าจอพรีวิวข้อมูล (`isExpanded`) ให้กว้างเกือบเต็มจอสำหรับตารางที่มีคอลัมน์จำนวนมาก
   - เพิ่มตัวเลือก **Encoding (UTF-8 / TIS-620)** ในหน้าเว็บ เพื่อแก้ปัญหาไฟล์ CSV ที่เกิดจากระบบเก่า (ภาษาต่างด้าว)

### 🐛 บั๊กที่ถูกแก้ไข (Bug Fixes)
1. **บั๊กดาวน์โหลดไฟล์แล้วได้ชื่อ zip.zip:**
   - *สาเหตุ:* โค้ด Frontend ตัวเก่าไม่รู้จัก Header `filename*=utf-8`
   - *วิธีแก้:* ปรับ Regex และการดึงข้อมูล Content-Disposition ในหน้าเว็บให้รองรับ UTF-8
2. **บั๊กสร้างไฟล์รวม (Merge) แล้วหน้ากระดาษติดกัน:**
   - *สาเหตุ:* docxcompose เอาข้อมูลไปต่อท้ายบรรทัดสุดท้ายของเอกสารเดิมโดยไม่ขึ้นหน้าใหม่
   - *วิธีแก้:* สั่งให้รันคำสั่ง `composer.doc.add_page_break()` แทรกก่อนที่จะนำไฟล์ถัดไปมาต่อ
3. **บั๊กหน้าจอขาว (White Screen) ตอนเปิดเมนู Auto-Gen:**
   - *สาเหตุ:* เผลอพิมพ์คำว่า ปีกกา ลงไปตรงๆ ในข้อความอธิบายบนหน้า JSX ทำให้ React เข้าใจผิดว่าเป็นคำสั่งโปรแกรม
   - *วิธีแก้:* ใส่เครื่องหมายคลุมเป็น String เพื่อให้แสดงเป็นข้อความธรรมดา
4. **บั๊ก CSS ช่อง Input และ Select สูงไม่เท่ากัน:**
   - *สาเหตุ:* เบราว์เซอร์คำนวณความสูงและเส้นขอบ (border) ของ 2 ช่องนี้ต่างกัน
   - *วิธีแก้:* ปรับปรุงคลาส .modal-input ใน styles.css โดยบังคับ box-sizing: border-box; และฟิกซ์ความสูงไว้ที่ 40px (และแยกความสูงของ Textarea ออกมา)
5. **บั๊ก IndexError ระหว่างสร้างไฟล์:**
   - *สาเหตุ:* ระบบไปเจอแถวที่ไม่มีข้อมูล พอพยายามไปดึงชื่อคอลัมน์แรก เลยพัง และทำให้ Array ของชื่อไฟล์ กับตัวไฟล์ มีจำนวนไม่เท่ากัน
   - *วิธีแก้:* ใส่เงื่อนไข len(context) > 0 ก่อนดึงค่า และปรับโครงสร้างให้ append ข้อมูลทั้ง 2 ชุดพร้อมกันที่ท้ายสุดของลูปเสมอ
6. **บั๊ก name used_names is not defined:**
   - *สาเหตุ:* ตอนเพิ่มระบบ Deduplication ตัวสคริปต์ค้นหาบรรทัดที่สำหรับประกาศตัวแปร used_names = {} ไม่เจอ ทำให้ตัวแปรไม่ถูกสร้างขึ้นมา
   - *วิธีแก้:* บังคับประกาศตัวแปร used_names = {} ไว้ด้านบนสุดก่อนเริ่มลูปประมวลผลข้อมูล
